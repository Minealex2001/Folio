# Folio Cloud — Integrations, Payments & Ink AI Drops

This document details subscription billing with Stripe, Admin entitlements management, and the Ink drop system for Quill Cloud AI under the Spring Boot backend architecture.

---

## 1. Stripe Billing & Webhook Integration

### Architecture

Stripe subscriptions and one-off ink drop purchases write to the PostgreSQL database via server-side Webhooks processed by the Spring Boot API (`/api/v1/stripe/webhook`). The Flutter client does not store or process secret keys; it interacts via API endpoints or opens checkout sessions generated by the backend.

### Environment Configuration

Configure these variables in `backend/.env` or system environment variables:

| Variable | Description |
|----------|-------------|
| `STRIPE_SECRET_KEY` | Stripe secret API key (`sk_test_...` / `sk_live_...`) |
| `STRIPE_WEBHOOK_SECRET` | Webhook endpoint signing secret (`whsec_...`) |
| `STRIPE_PRICE_FOLIO_CLOUD_MONTHLY` | Subscription Price ID (e.g. 4,99 €/month) |
| `STRIPE_PRICE_INK_SMALL` | One-off product price ID (300 drops) |
| `STRIPE_PRICE_INK_MEDIUM` | One-off product price ID (1,000 drops) |
| `STRIPE_PRICE_INK_LARGE` | One-off product price ID (2,500 drops) |
| `APP_PUBLIC_BASE_URL` | Application base URL for return redirects |

### Stripe Webhook Registration

1. Register your webhook endpoint in the Stripe Dashboard:
   - Endpoint URL: `https://<YOUR_API_DOMAIN>/api/v1/stripe/webhook`
   - Required events: `checkout.session.completed`, `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`.
2. Copy the signing secret into `STRIPE_WEBHOOK_SECRET`.

## 2. Admin Entitlement Grants (QA & Testing)

To grant subscription access or ink drops to a user without processing real payments:

```powershell
curl -X POST http://127.0.0.1:18080/api/v1/admin/entitlements/grant-cloud `
  -H "Content-Type: application/json" `
  -H "X-Folio-Admin-Key: dev-admin-change-me" `
  -d "{\"email\":\"user@example.com\",\"alsoStaff\":true,\"inkDrops\":1000}"
```

This endpoint updates `user_folio_cloud` in PostgreSQL and credits the specified ink drop balance immediately.

## 3. Ink Drops & Cloud AI System

Cloud AI features are exposed through the `/api/v1/ai/complete` endpoint in the Spring Boot API.

### Ink Consumption Model

Users consume **Ink Drops** for cloud AI operations. Drops are sourced from:
1. **Monthly Plan Refill**: Active subscribers receive monthly ink drop refills.
2. **Purchased Balance**: Purchased ink drop packs never expire and persist across subscription plan changes.

### Operation Base Costs

| Operation (`operationKind`) | Base Ink Drops |
|-----------------------------|----------------|
| `rewrite_block` | 3 |
| `summarize_selection` | 3 |
| `extract_tasks` | 6 |
| `summarize_page` | 6 |
| `generate_insert` | 9 |
| `generate_page` | 15 |
| `chat_turn` | 6 |
| `agent_main` | 16 |
| `agent_followup` | 9 |
| `edit_page_panel` | 9 |
| `transcribe_cloud` | 2 |
| `generate_image` | 15 (flat, no token surcharge) |
| `default` | 6 |

### Token Surcharges & Automatic Refund

- **Prompt Length Surcharge**: Extra ink drops added for prompts exceeding length thresholds.
- **Completion Token Surcharge**: Calculated dynamically from `usage.total_tokens`.
- **Automatic Refund**: If the AI inference provider fails after ink debiting, the transaction rolls back and ink drops are refunded automatically.
